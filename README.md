# 🚗 Classic Models – SQL & Power BI Data Analysis Project

## 📌 Project Overview
This project focuses on analyzing the Classic Models database using SQL and Microsoft Power BI. The main objective is to extract meaningful business insights from sales, customers, products, orders, and payments data.

SQL is used for data extraction, joining tables, and performing queries, while Power BI is used to create interactive dashboards and visualize business performance.

## 🎯 Project Objectives
- Analyze overall sales and revenue performance.
- Identify top 5 best-selling products.
- Analyze sales by product line and category.
- Calculate total profit and profit margin.
- Understand customer purchasing behavior.
- Analyze product-wise and customer-wise sales.
- Identify business trends and performance.

## 🛠️ Tools & Technologies
- **SQL:** Data extraction, joins, filtering, and aggregation.
- **Power BI:** Interactive dashboards and data visualization.
- **DAX:** Calculated measures and KPIs.
- **Excel:** Data exploration and preparation.
